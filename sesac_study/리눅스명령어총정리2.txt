tar는 반드시 옵션있어야함
-cf : 묶기(압축X) vs -xf: 풀기

tar -cf <data.tar: 만들 이름> <dir: 묶을 파일>   : -cf : 묶기(압축X) 
	ex) tar -cf data.tar ./dir
tar -xf <data.tar: 풀 파일> -C <풀 위치>   : -xf: 풀기, C지정안해주면 현재 pwd에 풀림
	ex) tar -xf data.tar -C ./dir
	확장자가 반드시 필요한건 아님(알아서 만들떄 지정해줌) -> tar -cd data ./data 해도 data는 tar형식

디스크는 /dev 안에 존재

디스크(데이터 저장하는 물리적 저장장치) 사용을 위한 작업 flow
1. 디스크 준비 및 파티션 생성(준비하고 쓸 부분 정하기)
   → 새 디스크를 추가하고 fdisk로 사용할 파티션을 생성
	$ 우선 ppt에 vmware에서 하드디스크1GB추가
	$ ls /dev/sd* 하면 새로생긴거 있음 (숫자 안붙은게 논리장치 아직 안생긴 새로운 디스크)
	$ sudo fdisk /dev/sdb  -> fdisk로 sdb를 논리적으로 분할
	$ n으로 새로운 파티션 분할
	$ p: primary -> 기본
	$ partition number1로 -> sdb1이됨
	$ first sector는 이미 정해짐 -2048
	$ last sector도 그냥 enter하면 기본값으로 설정
	$ p로 확인
	$ w로 파티션분할 저장
	논리적으로 디스크 파티션 설정하면 논리적 장치에 1 붙게됨 -> 얘를 포맷
		sdb라는 물리적장치에 대해 설정하면 sdb1, sdb2, .... 이렇게 파티션으로 논리적으로 나눠서 사용
	$ ls /dev/sd*하면 sdb1생성된것을 볼 수 있음

------------------------------------------------------------------------------------------------------------------------
2. 디스크 포맷(그 저장공간에 파일을 저장할 수 있도록 파일시스템을 만드는 것)
   → mkfs(make file system) 명령어로 파티션에 파일시스템(ext4, xfs 등)을 생성
	$ sudo mkfs.ext4 /dev/sdb1  #파일 시스템을 만드는 mkfs를 통해 /dev/sdb1 논리적 파티션을 ext4 파일 시스템 형식으로 변환 (파티션 포맷)

------------------------------------------------------------------------------------------------------------------------
3. 장치 연결(마운트)
   → mount 명령어로 파티션을 특정 디렉터리에 연결하여 사용할 수 있게 함
	sudo mount <옵션> <장치명> <디렉토리명> -> 어떤 장치를 어느 디렉토리에 연결하겠다
	$ mkdir /mnt/mydata    #디스크를 연결할 디렉토리를 생성 -> 주로 /mnt에 디렉토리 생성
	# touch /mnt/mydata/test1
	$ sudo mount /dev/sdb1 ./mydata	# 디스크와 디렉토리를 연결
	# ls ./mydata 하면 test1 잠시사라지고 lost+found자동생성된것을 볼 수 있음
	# touch ./mydata/test2
	mount | tail -1 로 마운트 무엇이 됐는지 확인

	$ sudo umount /dev/sdb1    # 장치 제거

NFS: **인터넷을 통해** 다른 리눅스 컴퓨터에 있는 디렉터리를 내 컴퓨터의 디렉터리처럼 사용하는 기능
	-> 리눅스의 하드디스크를 네트워크에 접속시키고 우리는 이 네트워크에 원격으로 접속해서 관리하는법!!!!!

-----------두 서버가 필요!!!! + 서로가 서로의 ip를 사용!!!!!!!-----------
1(서버VM). NFS 서버를 위한 패키지 설치(디스크 할당된 디렉토리 공유하는쪽)
	-> sudo apt install nfs-kernel-server

2(서버VM). 디렉토리 만들고 모든권한주기 -> 이 디렉토리를 공유 -> 얘는 뭐 디스크같은거 마운트 한게 아니라 그냥 순수 서버의 저장공간
	mkdir ~/share    -> chmod 777 share

3(서버VM).  /etc/exports: 어떤 서버의 디렉토리를 네트워크에 올릴지, 또 어떤 클라이언트가 접속할지 클라이언트의 ip주소 마지막줄에 추가 -> 우리가 여기 연결해서 파일 관리한다
	: [공유디렉터리] [클라이언트 ip주소-ip addr값] (옵션)
	ex) /home/woohyun/share 192.168.1.70(rw,sync) 를 /etc/exports 마지막 줄에

4(서버VM).NFS 서비스가 변경된 /etc/exports 반영해서 nfs서비스 시작
- sudo exportfs -a     → /etc/exports에 작성한 모든 공유 설정을 적용(export)
- sudo systemctl restart nfs-kernel-server     →  우분투, 데비안 계열의 NFS 서버 서비스를 재시작
#- sudo systemctl restart nfs-server # 로키, RHEL, CentOS 계열
- sudo exportfs -v 	→ 현재 적용된 NFS 공유 설정을 상세하게 확인 -> 추가된 자동 설정들

5(서버VM).방화벽 허용 
	 - sudo ufw allow nfs

---------------------------이제 다른 클라이언트 서버로-------------------------------------------------------

6(클라이언트VM). NFS 클라이언트 (공유된 디렉토리 가져다 쓰는쪽) 패키지 설치
- sudo apt install nfs-common # 우분투, 데비안 계열 설치 필요
# sudo apt install nfs-utils # 로키, RHEL, CentOS 계열

7(클라이언트VM). 클라이언트가 서버의 공유 디렉터리를 클라이언트 자신의 /mnt/share에 마운트 -> 서버 ip입력
sudo mkdir -p /mnt/share
sudo mount 192.168.1.37:/home/woohyun/share /mnt/share
	-> mount가 "이건 NFS 원격 경로구나”라고 판단해서 NFS용 마운트 도구를 이용해 연결하는 구조

8(클라이언트VM). 마운트 확인: mount | grep nfs   -> clientaddr 70, addr=37

9(클라이언트VM). /etc/fstab 파일 수정 -> 부팅할 때 자동으로 마운트되도록 등록하는 과정
	-> 마지막줄에 : [NFS 서버의 IP 주소와 공유 디렉터리] [마운트 지점] [파일시스템 종류] [옵션] [dump] [pass]
		ex) 192.168.1.37:/home/woohyun/share /mnt/share nfs defaults 0 0

10: 서버의 ~/share와 클라이언트의 /mnt/share가 같은 파일을 보여주게 됨
	-> 각각 cat으로 파일 생성하면 동시에 생성

================3티어 구축=================
1. 웹서버 패키지 준비
	sudo apt -y install apache2

2. 동적 웹 스크립트(PHP) 패키지 설치
	sudo apt -y install php
	php -v로 확인

3. /var/www/html에 info.php파일 생성
	sudo vi /var/www/html/info.php
		->밑에걸 적음 
		<?php				#PHP 코드라는 표시
			phpinfo();			#현재 서버의 PHP 버전, 설정, 모듈 등의 정보를 웹페이지로 출력
		?>       

4. mysql설치
	sudo apt -y install mysql-server	#mysql설치
	sudo apt -y install php-mysql	#php-mysql연동을 위한 패키지도 설치
	sudo systemctl start mysql		# mysql 서비스 시작

5. 워드프레스라는 오픈소스 웹 콘텐츠 관리 시스템 사용(우리는 개발자가 아니라 만들어진거 사용)
	wget https://wordpress.org/latest.tar.gz   # wget으로 워드프레스 압축파일 다운받아오기
	tar -xzf latest.tar.gz				# 받아온 파일 압축해제 및 풀기 -> wordpress 디렉토리가 생성됨
	sudo cp -r wordpress /var/www/html/	# /var/www/html에 이 wordpress파일 옮김 -> Apache가 웹으로 제공하는 /var/www/html/ 아래로 복사
	sudo chown -R www-data:www-data /var/www/html/wordpress  # 소유자,그룹 www-data로 변경 (아파치가 사용하는 소유자와 그룹)
	sudo chmod -R 755 /var/www/html/wordpress				# 권한도 변경

6. mysql 실행 및 프로프트 작성(wordpress에 쓰일 DB)
	sudo mysql -u root -p		# sql입력창 열림

CREATE DATABASE wordpress;			-> var/lib/mysql/wordpress로 저장됨
CREATE USER 'admin' IDENTIFIED BY '1234';
GRANT ALL PRIVILEGES ON wordpress.* TO 'admin';
FLUSH PRIVILEGES;
EXIT;

7. 워드프레스 설치 마법사  -> 여기서 워드프레스랑 DB 연동됨
	http://IP주소/wordpress로 이동
	-> 언어 설정하고 db이름, 사용자명, 비번 입력 (이 정보들 적으면 알아서 연동해줌)
	->만들 페이지이름,사용자,비번,이메일등입력
