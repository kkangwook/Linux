[vi/vim 핵심 명령어 정리]

※ vi는 기본적으로 명령 모드에서 시작
※ Esc = 언제든 명령 모드로 돌아가기


1. 모드 전환

i       : 현재 커서 앞에서 입력
a       : 현재 커서 뒤에서 입력
I       : 현재 줄 맨 앞에서 입력
A       : 현재 줄 맨 뒤에서 입력
o       : 현재 줄 아래에 새 줄 만들고 입력
O       : 현재 줄 위에 새 줄 만들고 입력
Esc     : 입력 모드 → 명령 모드


2. 커서 이동

h       : 왼쪽
j       : 아래
k       : 위
l       : 오른쪽

w       : 다음 단어의 시작으로 이동
e       : 다음 단어의 끝으로 이동
b       : 이전 단어의 시작으로 이동

0       : 현재 줄 맨 앞으로 이동
^       : 현재 줄의 첫 글자로 이동
$       : 현재 줄 맨 끝으로 이동

gg      : 파일 맨 처음으로 이동
G       : 파일 맨 마지막으로 이동
숫자G   : 해당 줄로 이동
예) 10G : 10번째 줄로 이동


3. 삭제

x       : 커서 위치의 문자 1개 삭제
dw      : 현재 위치부터 단어 삭제
de      : 현재 위치부터 단어 끝까지 삭제
d$      : 현재 위치부터 줄 끝까지 삭제
dd      : 현재 줄 전체 삭제

2dd     : 2줄 삭제
3dd     : 3줄 삭제

※ d + 이동명령 형태
dw      : 단어 방향으로 삭제
d$      : 줄 끝까지 삭제


4. 실행 취소 / 다시 실행

u       : 마지막 작업 취소(Undo)
U       : 현재 줄에서 했던 변경 취소
Ctrl+r  : 취소한 작업 다시 실행(Redo)


5. 복사(Yank) / 붙여넣기

yy      : 현재 줄 복사
yw      : 단어 복사
2yy     : 현재 줄부터 2줄 복사

p       : 커서 뒤/아래에 붙여넣기
P       : 커서 앞/위에 붙여넣기

※ vi에서는 복사를 yank라고 함


6. 변경(Change)

cw      : 현재 위치부터 단어를 삭제하고 입력 모드
ce      : 현재 위치부터 단어 끝까지 삭제하고 입력 모드
c$      : 현재 위치부터 줄 끝까지 삭제하고 입력 모드

※ c = 삭제 + 입력 모드 전환


7. 문자 바꾸기

r       : 현재 문자 하나 바꾸기
예) ra  : 현재 문자를 a로 변경

R       : Replace 모드
          입력하는 문자로 기존 문자를 계속 덮어씀


8. 검색

/문자열 : 아래 방향으로 검색
?문자열 : 위 방향으로 검색

n       : 같은 방향으로 다음 검색 결과
N       : 반대 방향으로 다음 검색 결과

예)
/hello
n
n


9. 치환

:s/old/new/       : 현재 줄의 첫 번째 old → new
:s/old/new/g      : 현재 줄의 모든 old → new
:%s/old/new/g     : 파일 전체의 모든 old → new
:%s/old/new/gc    : 파일 전체에서 하나씩 확인하며 변경

※ % = 파일 전체
※ g = 해당 줄에서 일치하는 것 모두
※ c = 변경 전 확인


10. 저장 / 종료

:w      : 저장
:q      : 종료
:wq     : 저장하고 종료
:x      : 저장하고 종료
:q!     : 저장하지 않고 강제 종료

※ : 명령을 입력하려면 먼저 명령 모드(Esc)에서 입력


11. 파일 열기

:e 파일명
        : 다른 파일 열기

예)
:e test.txt


12. 외부 명령 실행

:!명령어
        : vi를 종료하지 않고 Linux 명령 실행

예)
:!ls
:!pwd


13. 현재 위치 / 파일 정보

Ctrl+g  : 현재 파일명, 현재 줄 등의 정보 확인

:set number
        : 줄 번호 표시

:set nonumber
        : 줄 번호 숨기기


14. 괄호 이동

%       : 대응되는 괄호로 이동

예)
(  ↔  )
{  ↔  }
[  ↔  ]


15. 숫자 + 명령

명령 앞에 숫자를 붙이면 여러 번 반복

3w      : 3단어 앞으로 이동
5x      : 문자 5개 삭제
3dd     : 3줄 삭제
2yy     : 2줄 복사


[진짜 자주 쓰는 것만 압축]

입력
i       입력
a       커서 뒤부터 입력
o       아래 새 줄
Esc     명령 모드

이동
h j k l ← ↓ ↑ →
w       다음 단어
b       이전 단어
0       줄 처음
$       줄 끝
gg      파일 처음
G       파일 끝

삭제
x       문자 삭제
dw      단어 삭제
dd      한 줄 삭제
d$      줄 끝까지 삭제

복사/붙여넣기
yy      한 줄 복사
p       붙여넣기

취소
u       Undo
Ctrl+r  Redo

검색
/word   아래로 검색
n       다음 결과
N       반대 방향 결과

치환
:%s/old/new/g   전체 치환

저장/종료
:w      저장
:q      종료
:wq     저장 후 종료
:q!     저장 안 하고 강제 종료


[핵심 원리]

d = delete
y = yank(복사)
p = put(붙여넣기)
c = change
w = word
$ = 줄 끝
i = insert
a = append
o = open new line
u = undo

숫자 + 명령 = 명령 반복
예) 3dd → 3줄 삭제

동작 + 이동범위 조합 가능
d + w → dw → 단어 삭제
d + $ → d$ → 줄 끝까지 삭제
c + w → cw → 단어 변경
y + w → yw → 단어 복사
